Getting started
###############

Installation
============

Install django-simple-page using `pip`::

    pip install django-simple-page


Add `simple_page` to your Django project's `INSTALLED_APPS`::

    INSTALLED_APPS = [
        ...
        'django.contrib.admin',
        'simple_page',
        'reorder_items_widget',
        'mptt',
        'my_project',
        ...
    ]
